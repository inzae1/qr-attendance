# Passkey Attendance Upgrade

새 흐름
1. 관리자: ?admin=1
2. Passkey 탭에서 학생별 등록 링크 발급
3. 학생 휴대폰에서 링크 열고 Passkey 등록
4. 태블릿: ?kiosk=1
5. 관리자 PIN으로 키오스크 시작
6. 출근/퇴근 모드 선택
7. 학생이 15초 동적 QR 스캔
8. 학생 휴대폰의 Face ID/지문/화면잠금으로 승인
9. 출결 기록
